# n8n Clone Nextjs

Create your own **AI Automations** tool using Nextjs

## Getting Started

1. Clone the repo

   ```bash
   git clone https://github.com/asad-mujumder/n8n-clone-nextjs.git
   ```

2. Install **pnpm** if not already installed

   ```bash
   npm install -g pnpm
   ```

3. Install all the dependencies:

   ```bash
   pnpm install
   ```

4. Run the development server:
   ```bash
   pnpm dev
   ```
   Open [http://localhost:3000](http://localhost:3000) with your browser to see the application.
